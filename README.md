# 🎀 Kitty英语乐园（Hello Kitty 粉色主题 · 初中到高中分级英语学习）

> 面向英语零基础学习者的趣味英语学习应用 —— **完全免费、完全离线、零成本运行**。
> 从**七年级**起步，按年级一步一步进阶到**高三**：6 个等级 × 4 个主题 × 8 词 = **192 个核心词**。
> 网页版（GitHub Pages 免费托管，手机也能用）+ Windows 桌面版（Electron 打包 exe）双端交付。

## ✨ 这是什么？

一套「小猫 Kitty 带路」的英语学习乐园，包含 5 大功能：

| 功能 | 入口 | 说明 |
|---|---|---|
| 🏠 乐园首页 | 启动页 | 樱花粉入口页 + 可拖拽的 3D Kitty 立绘 + 4 个功能入口 + 每日单词推荐 |
| 🎯 单词闯关 | 首页 → 单词闯关 | **按等级循序渐进**：先选年级（七年级→高三），再进年级内的主题；四选一答题，图片+发音+音标，答对开心 Kitty、答错委屈 Kitty，赚取 ⭐ 星星；学完上一级 60% 解锁下一级 |
| 💬 情景对话 | 首页 → 情景对话 | 8 个初中生活场景（开学第一天/自我介绍/课堂互动/文具店/图书馆/问路/天气/周末计划），按年级由易到难排序；气泡对话，逐句点击发音，中英文对照 |
| 🧩 单词小游戏 | 首页 → 消消乐 | 中英配对消除游戏，3 个关卡按学段进阶（七年级词库 6 对 → 八九年词库 8 对 → 高中词库 10 对），通关奖励星星 |
| 📊 学习进度中心 | 首页 → 学习进度 | 每个账号的成绩卡片、7 天学习柱状图、**分级掌握度**（七年级→高三 每个年级的掌握进度）、个性化称号、全套单词表、学习时间统计，以及换设备数据同步 |

- **分级内容规模**：单词 **6 级 × 4 类 × 8 词 = 192 词**（🌱七年级 → 🌸八年级 → 🍀九年级 → 🌿高一 → 🌻高二 → 🎓高三，均含 emoji 配图 + 音标，词表参考人教版《Go for it!》/《必修·选择性必修》高频核心词）；情景对话 **8 个场景**；小游戏 **3 个关卡**。
- **解锁规则**：七年级默认解锁；之后每一级要**学完上一级 60% 的单词**（答对过至少 1 次即算学过）才会解锁，保证一步一步循序渐进。
- **账号注册 / 登录**：第一次使用先注册一个**学习账号**（账号 + 昵称 + 头像），登录后自动保存自己的全部学习记录；一台电脑可以注册多个账号，家里几个小朋友各学各的，成绩互不干扰。
- **数据只在本机**：账号、密码、学习记录全部保存在**本机浏览器（IndexedDB）**，**不经过任何服务器，不上传任何数据**；学习时也不需要联网（离线也能用）。忘记密码没关系：删掉旧账号重注册即可（旧学习记录无法找回）。
- **跨设备同步（电脑 ↔ 手机）**：同一个账号在电脑、手机上想用同一份进度？在「学习进度中心 → 🔄 换设备 / 数据同步」一键生成一串**分享码**（或下载 JSON 文件），在另一台设备粘贴导入即可，可选择**合并**或**覆盖**。全程离线、零成本。
- **手机 App 化（PWA）**：手机浏览器打开后，可「添加到主屏幕 / 下载安装」成独立 App，断网也能用。（详见「📱 手机端 PWA」）
- **发音**：使用系统自带语音合成（Web Speech API / Windows TTS），**无需联网、无需任何付费接口**。

## 🚀 怎么运行

### 方式一：网页版（浏览器直接打开也行，但推荐本地服务器）

```bash
# 需要 Node.js（≥ 16 即可，无需安装任何包）
npm run serve
# 打开浏览器访问 http://localhost:8080
```

不启动任何服务也能用：直接双击 `src/index.html` 或用浏览器打开即可
（全站不使用 ES 模块，`file://` 协议下可正常运行）。

### 方式二：Windows 桌面版（Electron，仅开发依赖）

```bash
npm install          # 安装 electron 与 electron-builder（需要联网）
npm start            # 本机启动桌面应用
npm run dist         # 打包 Windows 便携版 + 安装版 → dist/
# 或者单独打包：
npm run dist:portable   # 便携版：绿色单文件 exe，拷贝即用
npm run dist:installer  # 安装版：NSIS 安装向导
```

打出来的 exe 在 `dist/` 目录，双击即可使用，**不需要联网，也没有任何服务器成本**。

## 🔐 账号与隐私说明（注册 / 登录）

- **第一次使用**：打开应用会先进入「登录页」，点「去注册一个」→ 输入**账号**（2~20 位字母/数字/下划线）、**昵称**、选个**头像**、设**密码**（至少 3 位），注册完成自动登录。
- **数据存哪里**：账号、密码、学习记录全部保存在**本机浏览器**的 IndexedDB 里，**不经过任何服务器、不上传、不联网** —— 这是「零成本 + 离线可用」的代价：账号只在**这台设备**上有效。
- **换设备怎么办**：用「学习进度中心 → 🔄 换设备 / 数据同步」的**分享码**（或导出 JSON 文件）把数据搬到新设备后，在那边重新注册一个账号粘贴导入即可。
- **同一台设备多账号**：家长和孩子各注册一个账号，学习记录完全隔离；「我的账号」里可以随时「退出登录 / 换账号」。
- **忘记密码**：本地验证无法找回（密码只在本机、不可逆加密保存），删除旧账号重新注册即可（旧学习记录无法找回）。
- **删除账号**：普通账号在「我的账号」弹窗右下角「删除我的账号（含全部数据）」，需输入当前密码确认；管理员账号受保护，不可被删除。
- **管理员**：本机内置一个管理员账号（最早创建、带 👑 徽章、用户列表里显示「受保护」），拥有「本机账号管理」面板（查看/删除本机普通账号）。管理员身份仅用于本机管理，不影响其他账号的正常学习。
- **隐私声明**：本应用全程无网络请求（仅学习内容与本机存储），**不会收集、上传任何个人信息**。

## 📱 手机端 PWA（网页当 App 用）

手机浏览器打开网页版后，可以把「Kitty英语乐园」**添加到主屏幕**，像 App 一样使用，**断网也能用**（Service Worker 缓存了全部资源）：

账号数据存在手机浏览器本地（IndexedDB），和电脑上的**同一账号互不相通**；想两边合并进度，请用「学习进度中心 → 换设备 / 数据同步」的**分享码**或导入文件。

## 🤖 ZyCode 迭代更新指引（给下一版自己看）

本项目为**模块化纯前端**，任何更新动一行代码即可，下面是「改哪、怎么改、改完怎么测」的完整地图。

### 1. 加单词 / 改单词

**改**`src/js/data/words-data.js`：

- 等级定义在 `Words.levels`（6 级：1=七年级 … 6=高三，改 `name/emoji/tag/desc` 即可）；
- 每个主题是一个 `Words.registerCategory({...})`，**必须带 `level` 字段**，在 `words` 数组里加一行：

```js
{ level: 2, id: 'sport', name: '运动日常', emoji: '⛹️', desc: '跑跳打球', words: [
  { id: 'run', en: 'Run', zh: '跑', emoji: '🏃', ipa: '/rʌn/' }
] }
```

- `id` 全局唯一（不重复即可）；`emoji` 可以用任意 emoji 当配图；
- 新主题自动出现在：该等级的闯关、进度中心分级掌握度、对应学段的消消乐词池。

### 2. 加情景对话

**改**`src/js/data/dialogues-data.js`：复制一个 `Dialogues.registerScenario({...})` 块，
改 `id / level / title / emoji / desc` 和 `lines` 数组（`{ who: 'kitty'|'friend', en, zh, emoji }`）。
`level` 越大排越后（1=七年级 … 4=高一），场景列表自动按等级排序。

### 3. 加游戏关卡 / 改难度

**改**`src/js/data/game-config.js`：在 `levels` 数组加：

```js
{ id: 4, name: '宇宙终极', desc: '12对单词 · 挑战极限', pairs: 12, cols: 4, stars: 8, source: 'l3' }
```

`pairs` 是配对数；`source` 是出题学段：`'l1'`=七年级词库、`'l2'`=八/九年级词库、
`'l3'`=高中词库（不写则从全库随机取词）。

### 4. 加新功能页

1. 在 `src/js/features/` 下新建 `xxx.js`，按现有页面（如 `home.js`）的结构：
   用 `(function (NS) { ... })(window.App.Features.Xxx ||= {});` 包裹并暴露 `render()`；
2. 在 `src/js/core/router.js` 的 `routes` 里加一行 `'#/xxx': ...`（抄 `#/quiz` 的行）；
3. 在 `src/index.html` 页面底部加 `<script src="js/features/xxx.js"></script>`；
4. 首页入口：在 `src/js/features/home.js` 的入口卡片处照抄一个按钮。

### 5. 换主题色 / 换小猫形象

- 主色：`src/css/theme.css` 中的 CSS 变量与自定义类；
- 小猫：`src/js/ui/kitty.js` 是**原创 SVG 角色**（非任何官方 IP），可以用任意矢量软件重画替换。

### 7. 易踩的坑（前车之鉴）

- 路由 query 参数全是**字符串**：`levelId` 是 `"1"`，`levelId + 1` 变成 `"11"` —— 记得 `Number()`。
- **`Words.byLevel(id)` 返回的是该级的类别数组，不是等级对象！**
  要取「七年级」这个名字请用 `Words.levels.find(l => l.id === 1).name`；要取单词用 `Words.listByLevel(id)`。
- `App.Data.Words.byCategory(id)` 返回的是**分类对象**，不是单词数组；
  取单词数组请用 `App.Data.Words.list(id)`。
- `Store.listUsers()` / `Store.addUser()` 返回 **Promise**，要 `await`/`.then` 后再取结果
  （`addUser` 内部会自动 `enter`，不 await 的话当前用户还是空的，`getOverview()` 会是 null）。
- 弹窗行渲染回调参数别叫 `u` —— 模块里的 `u()` 是取 `App.Utils` 的惰性助手，会被参数遮蔽。
- `Store.login()` / `Store.register()` 失败时是 **`Promise.reject(error)`**（错误消息是中文），
  不是返回 `{ ok: false }` —— 页面里记得先 `.then`、后 `.catch(err)`（`features/auth.js` 有现成写法）。
- 登录守卫在 `app.js` 的 `bus.on('route')` 里：新加路由时，**游客放行的路径必须列入放行名单**
  （现在是 `/auth` 与 `/auth/register`），否则会被守卫强制弹回登录页。
- `Store.addUser` 是旧版（无账号时代）遗留入口，新功能一律用 `Store.register(username, password, nickname, avatar)`。
- **管理员种子**常量在 `src/js/core/store.js` 顶部 `ADMIN_SEED`（含账号密码），只做本机初始化兜底；
  账号密码**永远不要**写进 README、AI_GUIDE 或任何用户可见文档。
- 所有新 JS 用**经典脚本 + 全局命名空间**（`window.App.X`），不要用 ES module ——
  `file://` 协议下 module 会被 CORS 拦死，桌面版和离线场景全完。
- 全局搜索 `App.DB.open` 时注意：真正公开的初始化 API 是 `App.DB.ready`。

## 🛠️ 技术栈

| 层 | 选择 | 说明 |
|---|---|---|
| 前端 | 纯 HTML + Tailwind CSS + 原生 JavaScript | 无框架、无构建步骤 |
| 存储 | IndexedDB（localStorage 兜底） | 每个账号独立记录，刷新不丢 |
| 发音 | Web Speech API | 系统自带，无牌照无费用 |
| 音效 | WebAudio 合成音 | 叮叮当当的小音乐 |
| 桌面 | Electron + electron-builder | 主进程/预加载脚本与网页解耦 |
| 图表 | 纯 CSS/div 柱状图 | 零依赖 |
